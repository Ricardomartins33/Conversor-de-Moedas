# 💱 Conversor de Moedas

Aplicação web de conversão de moedas desenvolvida com **HTML, CSS e JavaScript**.
O projeto permite ao usuário inserir um valor e converter para diferentes moedas de forma rápida e dinâmica.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📚 Funcionalidades

* Inserir valor para conversão
* Selecionar moeda desejada
* Conversão dinâmica com JavaScript
* Formatação de valores em moeda

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido para praticar conceitos de **desenvolvimento Front-End**, manipulação do **DOM**, eventos em JavaScript e formatação de valores.
